# 经验卡片目录

插件自带的卡。每张卡是一条科研上的做法，写明道理、怎么用和出处。认同程度三档：共识（至少三个独立来源，手册算一个）、有出处（一到两个来源）、有分歧（名家意见不一，两派都写）。项目里 .duck/cards/ 的卡是学生和课题组的规矩，和这里同号时以那边为准。卡上的 sources 只列支持这条做法的来源，分歧里提到的人列在卡末的出处里。
