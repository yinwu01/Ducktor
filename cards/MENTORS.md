# 名家怎么想

顶级研究者和导师写过的讲科研的文章，每篇用我们自己的话转述要点，附原文链接。/duck-why、/duck-learn 和平时讲「为什么」时，名家的名字和看法只能从这里、卡片（cards/INDEX.md）或手册（handbook/）里取，不从记忆里补。

用的时候：
- 一条看法只代表这个人在这篇文章里的说法。这里都是转述，讲给学生时不加引号，不说成原话。
- 下面「意见不一的地方」里的事，两派都讲，并说清各自适用的条件（领域、阶段）。
- 这些建议都有前提。Nagpal 说自己后来不再照单全收别人的建议，Tao 说他的建议很泛，Guo 在《The Ph.D. Grind》里自称只是一个数据点。讲的时候带上适用前提，别当成定律。
- 名家是用来帮学生理解一条道理的，一次至多一到两位，不堆名人名言。

来源在 2026-10-15 逐条核实过（读到了正文，或经存档、授权转载读到正文），核实方法和许可见 docs/research/C-expert-corpus.md。只核到书目信息、没读到正文的几篇没有收。

## 多家都这么说

至少三个独立来源支持，可以当作稳的道理讲。

| 道理 | 谁这么说 |
|---|---|
| 动手、动笔之前，先写出一到三条可检验的核心主张或贡献 | Karpathy、Eisner、Peyton Jones、Widom、Nanda、Mensh 和 Kording、MIT Comm Lab |
| 选题看重要性，也看可行性，必须有攻击路径 | Hamming、Alon、Schulman、Karpathy、Durand、Patterson |
| 以最快的速度降低不确定性：最小实验、toy model、先过拟合、尽早失败 | Steinhardt、Freeman、Durand、Perez、Patterson、Karpathy、J.-B. Huang |
| 证据先于叙事：试着证伪自己，分离提升的来源，写明局限，不夸大 | Steinhardt、Freeman、Tao、Lipton 和 Steinhardt、Kapoor 和 Narayanan、Widom、Nanda |
| 读者优先，把话讲清楚本身就是贡献 | Hamming、Durand、Peyton Jones、Knuth、Steinhardt、Gopen 和 Swan、Mensh 和 Kording、Olah 和 Carter、陈天奇 |
| 报告少而精：一到三个要点，反复强调，结尾给贡献 | Durand、Peyton Jones、Fatahalian、Winston、Hill |
| 尽早、经常地找外部反馈：内部截止日、彩排、找人挑刺、别躲着导师 | Karpathy、Freeman、Perez、Patterson、J.-B. Huang、Nanda、Mensh 和 Kording、陈天奇 |
| 审稿和 rebuttal 对事不对人：先概括贡献，保持建设性；被问到的信息就直接给 | Durand、J.-B. Huang、Roscoe、A. J. Smith、Daumé III |

## 意见不一的地方

讲到这些事时，两派都摆出来，说清各自适用的条件。

| 议题 | 一派 | 另一派 |
|---|---|---|
| 定题的节奏 | Alon：新人头三个月别急着定题 | Perez：今天讨论，明天出结果。两人的领域不同，一个是湿实验，一个是 LLM 实证 |
| 什么时候追求雄心 | Karpathy、Schulman、Ruder：要有雄心，追求十倍的提升 | Alon：新生先做容易的题，拿到正反馈；Tao：别过早执着于大问题 |
| 增量工作 | Karpathy：「incremental」是最坏的评价 | Schulman：服务于大目标、又足够简单的增量是有用的；Patterson：只在少数几个点上创新 |
| 什么时候读文献 | Hamming：问题想清楚之前先别看别人的答案，读文献主要是为了找问题 | Ruder：广泛阅读；Freeman：别对大量相关文献一无所知 |
| 快和稳 | Perez：强烈偏向速度，追求实验的吞吐量 | Freeman：慢下来才能快，一次只改一个变量 |
| 论文结构的惯例 | Shewchuk：不要段落式目录，不要空洞的结论 | Widom：贡献要点兼作导航，保留简短的结论；Steinhardt：可以打破全局结构 |
| 选题看什么 | Schulman：目标驱动 | Alon：听自己内心的声音，追求自我表达 |
