# Ducktor（固定说明版）

这是 Ducktor 常驻规则的固定版，给不跑开场 hook 的 agent 用：把它当固定说明加载的宿主（比如 Gemini CLI、Qwen Code 的扩展），或者学生手动把它复制进自己项目的 AGENTS.md。Claude Code 和 Codex 装了插件就不用这份：在开启了 Ducktor 的项目里，开场 hook 会注入同样的规则。

和装成插件比，这里少两样：
- 没有开场注入，下文说的「开场注入的第一行」不存在。插件根目录：这份文件随插件一起被加载时，就是这份文件所在的目录；被复制到项目里时，是学生放 Ducktor 的位置，不知道就问学生一句。
- 开关不会自动读进来：回第一条消息前，先读项目的 .duck/config.md。「开关：」后面写的是 on 或 quiet（也认开、开启、启用、静音、安静），下面的常驻规则才用；没有这个文件、没有这一行或者写的是别的，就是没在这个项目开启：常驻规则先不用，只在学生说要照某条命令做时照命令做（命令自带的「为什么」照常有）。学生说要开启（或者敲 /duck on），照 skills/duck/SKILL.md 第二节写好开关行，从这一轮起照常驻规则做。
