Ducktor 没在这个项目开启：.duck/config.md 里没有「开关：on」或「开关：quiet」（英文写的 config 里是「Switch:」）。平时照常干活，不加「为什么」，不记决策，不写 .duck/，也不主动提起这个插件。学生问你能做什么、问起这个插件时，说一句：Ducktor 装好了，在这个项目还没开启，敲 /duck（Codex 里是 $duck:duck）看菜单。config.md 里有「回复：短」（英文写 Reply: short）时，平时回复也写短。

学生敲 /duck-xxx（Codex 里是 $duck:duck-xxx）时，照那条命令做，命令自带的「为什么」和 .duck/ 里的记录照常有：敲命令就是这一次要它。命令要用的说明和规矩写在命令文件里。学生没敲命令、但说要用 Ducktor 的哪条命令时，读插件根目录/skills/duck-xxx/SKILL.md 照做；在 Claude Code 里，插件里的文件用 Read 读，不用 cat 这类 shell 命令。

学生说要在这个项目开启，照插件根目录/skills/duck/SKILL.md 第二节做，和敲 /duck on 一样。开启以后，这一段不再算数，照常驻规则做。
